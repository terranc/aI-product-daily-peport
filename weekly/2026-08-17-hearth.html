家庭AI 助手共享工作区生活管理智能家居

Hearth — 家庭共享 AI 工作区 · 每周深度分析

Hearth 是面向整个家庭的共享 AI 工作区：家庭计划、笔记、日程、成员与固定仪式统一放在一个实时同步的空间里（类似带 AI 助手的共享版 Obsidian）。最特别的是，AI 助手能基于家庭笔记直接编写并运行自定义小应用——预算追踪、航班监控、菜谱规划等，应用在沙箱中运行、遵循家庭设定的规则，联网和登录需显式审批。

增长证据

产品于 2026-08-13 正式发布（Bear 官方博客 + Show HN 同步上线），目前为 beta 阶段，无公开营收/用户/融资数据（未披露）。Show HN 发布当天约 8-9 分、1 条评论线程（Algolia API 实测），属早期小规模冷启动；GitHub 组织 bearbuild 已建（hearth-apps 2026-08-13 推送、playground 2026-08-06 推送、playwright-mcp 2026-07-25），三个仓库当前均 0 stars，开源推广尚未开始。官方路线图：Playground 开源为库、Hearth 开源为 demo app、用户间共享 skills/apps、开放 ConstructionBear（同底座建筑产品）——均在「coming soon」。定价：Hearth Standard $12/月（含 $8 AI 额度），新用户 $5 试用额度无时限、无强制订阅，文件免费归用户所有。

社区反馈

HN 讨论规模尚小但质量高：jmtulloss 亲自在评论区回应 IoT 集成问题，说明「任何有 API 的设备都可通过配置带 API token 的 proxy 接入，agent 可写 app 调用设备而不接触密钥」，并已把 Home Assistant 媒体控制 demo app 公开到 github.com/bearbuild/hearth-apps（含 Google Workspace、Presentations、Travel Map、Home Assistant 四个开源 demo）。aigregator.com 已收录产品页（2026-08-14 更新，标注 freemium/Web 平台），暂无第三方评测。整体社区热度处于起步期，讨论集中在架构理念（vertical harness / Software for One）而非使用体验。

近期更新

处于活跃 beta 迭代期：2026-08-13 产品上线当日即推送 hearth-apps 仓库，2026-08-06 更新 Playground 库；HN 评论中作者表示持续打磨沙箱/策略层与 demo 应用生态。官方博客规划「未来数周数月有更多发布」，包括开源、应用共享市场和 ConstructionBear 开放访问，属高频率推进状态。

市场定位

家庭 AI 助手赛道 2025-2026 正经历洗牌：Milo 已于 2026 关闭、Maple 被 Wander 收购并定于 2026-12-31 关停，传统玩家（Cozi/TimeTree/FamilyWall）几乎无 AI，AI 原生新秀（Honeydew、Nori、Ohai、AlphaMa、Concairge、Kinhold）多为「日历+任务+语音」式助手或邮件解析层。Hearth 以「共享工作区 + agent 编写运行自定义应用」切入，定位更接近可编程的「家庭 OS」而非单点工具，当前同赛道无直接对位竞品；其母公司 Bear 同时以同一 Playground 底座服务建筑行业（ConstructionBear，34 类施工文档 AI 生成，2026-07 开放首批 50 用户），显示跨垂直复用能力。

差异化

① 应用即产物：AI 不止问答，而是写出真正运行的交互式应用（预算/航班/菜谱/家庭自动化），且每个应用可沉淀为 agent 后续工具；② 家庭级安全边界：锁定沙箱 + 策略引擎逐项审批 + 凭据 vault（密钥不出库）+ 离线全量副本 + 全量可撤销编辑历史，面向「不擅长技术也要安心」的普通家庭设计；③ 明文规则、家庭自持控制权，边界可随时查看/收回；④ 开源路线 + Playground 可编程底座，理念上把「AI harness」从工程师下沉到家庭/建筑等垂直领域；⑤ 定价模式「付费买 AI 工作、不买文件访问权」，文件永归用户。
