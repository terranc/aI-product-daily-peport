Monish（把 AI Agent 挂到锁屏）

往 Claude Code、Codex、Cursor、n8n 或任意脚本里粘一行，AI 任务的实时进度就会出现在 iPhone 锁屏与灵动岛；跑完/失败会提醒，部署、发送、花钱前要先在通知里点「同意/拒绝」。

8 访问官网 App Store💬 ChatGPT 分析

目标受众

会同时跑多个长任务 Agent、又不愿一直盯着终端的开发者和自动化玩家。

使用场景

  • 通宵跑 Agent 时在锁屏看实时进度与完成提醒
  • 部署/发邮件/付费前在通知上一点批准或拒绝
  • 把 n8n 工作流的运行状态和关键指标（如订单数）投到灵动岛
  • 任务失败时在免打扰时段照样响铃提醒

设计初衷

作者团队常年并行跑多个 Agent，最常踩的两个坑是：Agent 卡在一个是非题上等了一小时没人理，以及任务早就跑完了自己还在刷终端。Monish 就是把这两个瞬间搬到手机上。

解决什么问题

解决 Agent 长时间空等人工确认、以及人反复回到电脑前查看状态的浪费；顺带给了「花钱/发布前的人工闸门」这一层安全把控。

评分理由

切口极准——不是再造一个 Agent，而是补上「人在外面时怎么管 Agent」这块空白，一行接入、免费无账号，落地上手成本几乎为零。扣分在于消息经其服务器中转（留存 48 小时），且主要面向 iOS。

对标竞品

AgentValley
同样做 Claude Code 多 Agent 总览，但只在 Mac 刘海屏上显示，人离开电脑就看不到。
Pushover
通用推送服务，能发通知但没有「在通知上批准 Agent 动作」的双向交互。
ntfy
开源自建推送，隐私更好，但需要自己搭，且无审批回传与灵动岛实时卡片。
