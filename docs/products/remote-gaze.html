远程桌面Apple 生态无服务器直连隐私优先

Remote Gaze

把整台 Mac 原生投到 iPad/iPhone 上：最高 120fps、支持触控与文件拖拽，无账号无中转服务器，外出时端到端加密直连。

8 访问官网💬 ChatGPT 分析

目标受众

手里有一台闲置 Mac mini 或 MacBook，希望用 iPad/iPhone 随时随地调用其算力的 Apple 用户。

使用场景

  • Mac mini 不接显示器当常开服务器，用 iPad 连上去做事
  • 在家局域网内 120fps 直接操作 Mac 应用
  • 外出时经 UPnP 打洞直连，Face ID 解锁后使用
  • 把 iPad 上的文件拖到 Mac 桌面
  • 单窗口「App 模式」把某个 Mac 应用放大成 iPad 原生体验

设计初衷

作者认为远程桌面不该经过第三方云中转，也不该强迫你注册账号。于是做成两端的原生应用：Gaze Host 在 Mac 上采集屏幕与声音，iPad/iPhone 端直接加密连过去。

解决什么问题

现有的远程桌面要么走云端中继（隐私与延迟双重损失），要么配置复杂。Remote Gaze 用一次配对码 + Secure Enclave 密钥解决了鉴权，用直连把延迟压到接近本地，同时给了「无头 Mac mini」这个明确的使用场景。

评分理由

把「无账号、无服务器、原生 120fps」三件事同时做到，是同类产品里少见的取舍。扣分在于依赖 macOS 26 / iOS 26 的新系统，且外出访问需要路由器支持 UPnP。

对标竞品

Jump Desktop
Jump Desktop 支持多协议但需账号或手动配置；Remote Gaze 只做 Apple 自家设备间直连，配对即用。
Screens
Screens 是老牌 Mac 远程工具（付费），Remote Gaze 主打 120fps 与无中转架构。
Tailscale + VNC
Tailscale 组网后仍要配 VNC 服务器，分辨率与帧率体验远不如 Remote Gaze 的原生串流。
