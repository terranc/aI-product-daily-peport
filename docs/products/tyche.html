Tyche（iPhone 上会自己动手的 AI 浏览器）

一个内置 AI agent 的 iPhone 浏览器：你正常浏览网页，随时可以把「查详情、比价、下单、填表」这类下一步交给它，它会自己搜索、点链接、填表单，你可以看着它做、随时接管，也能切到别的 App 让它后台继续。

7 访问官网 App Store💬 ChatGPT 分析

目标受众

用手机处理大量网页事务的普通人——订票、比价、填各种线上表单的用户

使用场景

  • 在商品页直接问「这个和上一页那个哪个更划算」
  • 把订票、填报名表这类多步操作整段交给它执行
  • 让它一边翻页一边总结长文内容
  • 做完一步后自己接手核对，再交回去继续
  • 切到微信回消息时让它继续在后台把流程跑完

设计初衷

开发者的判断是：AI 不该只在后台替你做决定，而应和人并肩工作。所以 Tyche 做成一个正常浏览器 + 可召唤的 agent，把「要不要继续、由谁来点」的控制权留在用户手上。

解决什么问题

解决手机端在网页上做多步操作又慢又烦的问题，同时回避了纯后台 agent 的两大隐患：用户不知道它在干什么、以及不敢让它代为付款或提交。

评分理由

把 agent 装进浏览器并保留「看得见、随时接管」的控制感，在手机这个最需要省事的场景里方向对。但目前仅 iOS、上线一天成熟度未知，购物付款类操作的实际可靠性还需时间验证。

对标竞品

Perplexity Comet
同样把 AI agent 做进浏览器，能力更强但主打桌面端，手机上体验受限。
Arc Search
以「帮我浏览」生成摘要见长，偏向信息整理，不擅长替你完成下单、填表这类操作。
Safari + Apple Intelligence
系统级集成、免费且隐私好，但 agent 能力保守，几乎不跨站执行多步任务。
