AI 阅读电子书边读边问本地朗读开源免费

Readr（AI 电子书阅读器）

一款可以「对话」的免费开源电子书阅读器：读到不懂的段落选中即问，答案以书中原文引用为据显示在页边，超出书本的部分会明确标注来源；内置设备端神经语音，可从当前页开始朗读、自动翻页续听；自带 API Key 或用 Mac 上的本地 Ollama 模型，无账号、无服务器、无遥测，支持 iPhone/iPad/Mac。

8 访问官网 App Store💬 ChatGPT 分析

目标受众

经常读电子书、希望边读边答疑解惑的深度读者与学习型用户

使用场景

  • 读英文原著或技术书遇到不懂的段落，选中直接问「这句话什么意思」，答案带书中出处
  • 读到科幻/科学设定时追问「这在现实中成立吗」，AI 明确区分书内知识与外部常识
  • 眼睛累了按 Listen 从当前页开始听书，阅读与听书进度无缝衔接
  • 读完把高亮和批注一键整理成 Markdown 笔记或文章草稿
  • 隐私场景：配本地 Ollama 模型，整本书记录不出设备

设计初衷

作者自己读书时总把不懂的段落复制到聊天窗口提问，答完再回书里找位置，深感割裂，于是把「提问」直接做进阅读器：答案落在页边、以书本原文为引用基准，既防 AI 胡编，也把好奇心的兔子洞拉回书本身；朗读、笔记导出都围绕「不打断阅读流」设计。

解决什么问题

解决「读书想查证/提问必须跳出书本开浏览器、回来还要找阅读位置」的割裂体验；并以「书中引用优先」的答案机制对抗大模型幻觉，让提问与阅读融为一体，同时提供免费开源+BYO Key 的隐私友好方案。

评分理由

产品思路克制且完成度高——把 AI 问答内嵌进阅读流并强制引用书中原文，直击深度读者真实痛点，PH 首发即上每日榜前列；免费开源、隐私架构干净（BYO Key/本地模型）。扣分点：AI 问答需自备 API Key 有入门门槛，且不支持 Kindle 加密书。
