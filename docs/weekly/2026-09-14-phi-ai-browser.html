Phi — AI 浏览器（macOS） · 每周深度分析

市场定位

2026 年 AI 浏览器赛道呈三强格局：OpenAI Atlas（最强代理、ChatGPT 生态）、Perplexity Comet（全平台免费、研究工作流最强）、Dia（最佳 UX、Skills 系统、Atlassian 旗下企业化）。主流浏览器（Chrome+Gemini、Edge+Copilot、Brave Leo、Opera Neon）也在快速加 AI 功能。Phi 定位于「独立小团队 + macOS 原生 + 本地优先 + 开源可审计 + 代理友好」的差异化 niche，面向开发者、隐私敏感用户与 AI 代理早期采用者，不与巨头正面拼用户量。核心优势：Chromium OS 级别的技术积累（FydeOS 团队背景）、独立中立的定位（不像 Atlas/Comet 绑定自家 LLM）、开源透明度建立信任、代理互操作（支持外部 agent 驱动）。核心风险：仅 macOS Apple Silicon 平台，用户基数受限；大厂（尤其 Google/Apple）一旦下场做真正的 AI 原生浏览器，独立团队压力巨大。

差异化

  1. 人机共驾的代理架构：Phi 不是「浏览器里塞个 AI 聊天框」，而是把 AI 代理设计成浏览器的一等公民——代理与人共享同一个窗口、同一份登录状态、同一段浏览历史，用户可以随时接管或监督。v
  2. 4 起还开放了外部代理（Claude Code / Codex 等）直接驱动 Phi 的能力，这是其他主流 AI 浏览器尚不支持的。
  3. 本地优先 + 开源透明：macOS 客户端完整开源（Apache
  4. 0），记忆文件存在本地可读可删，AI Guardrail 在本地过滤敏感信息后才发送云端，支持通过 Sentinel 连接 Ollama/LM Studio 本地模型。在 AI 浏览器普遍「数据全走云端」的背景下，Phi 的隐私姿态是最彻底的之一。
  5. 独立中立：不像 Atlas 绑定 OpenAI、Comet 绑定 Perplexity，Phi 不绑定任何特定 LLM 厂商，用户可以选云模型也可以选本地模型，团队动机被定位为「让你喜欢这个浏览器」而非「把你锁进自家生态」。
  6. 技术深度：创始团队有 FydeOS（Chromium 操作系统级别）经验，对 Chromium 引擎的理解远超一般浏览器创业团队。
  7. Phi Link + Sentinel 的体系化设计：Sentinel 后台守护进程支持定时/异步/事件驱动 AI 任务，Phi Link 通过 Telegram 等即时通讯工具实现手机远程调用浏览器，形成「桌面浏览器 + 后台代理 + 移动入口」的完整闭环。
